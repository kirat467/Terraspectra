# Terraspectra
TerraSpectra is an AI-powered precision agriculture project that uses hyperspectral satellite imagery, 3D-CNN, and Vision Transformers to detect early crop stress and forecast potential diseases through intelligent geospatial analysis and interactive GIS heatmaps.
