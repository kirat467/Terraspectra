# Mentor se poochne wale sawal (Day 1 pe bhejo)

1. Disease labels ka source kya hoga? Company ke paas field data hai?

4. Hyperspectral sensor preference (EnMAP / PRISMA / other)?
5. Model team ko dataset kis format me chahiye (.npy / HDF5 / .tif)?
6. Patch size ya pixel-level classification?
7. Forecasting ke liye time-series (multi-date) data chahiye?
8. Progress update kitne din me aur kis format me dena hai?
9. Compute / storage limit kya hai (GBs of data)?
10. Final demo me meri taraf se kya dikhana hai?
